# 地标与旅人聚光验证

2026-10-30。本轮实装：NEX / PGOS 实体像素字块立牌；Win10 蓝色 (#0078d7) 四窗格立体徽标；三个主题按 1/2/3 编号。主体场景背景保持原色，另外生成 A 海面 / B 浮岛 / C 沙盘三版设计供选择。

聚光由跟随角色投影位置的柔边暗场、三维八面光柱、脚下八边光环组成。首次主动访问有 0.65 秒出发提示，角色本身放大至 1.15 倍。光效在步行和施法期间跟随，取消或进入详情后平滑退出。沿用原先不受光照影响的分色材质，避免为全场换材质而改变像素风格；光效不是物理阴影求解。

验证：
- 浏览器首次访问 Nex：departure=true、walked=0、spotlight=0.80；随后开始行走，spotlight=1.00。见 interactions.json。
- 行走中 Escape 取消，角色留在实际位置、spotlight=0.00；再次访问成功到达 Nex，详情打开后 spotlight=0.00。
- 1440×900 全景下 NEX / PGOS 立牌、Win10 四窗格可见，保存 overview.png / win10.png。
- 390×844 全景与旅程检查，文档无横向溢出，聚光跟随角色；手机全景仍以主题导航为主，展区放大后阅读模型细节。
- 减少动态效果：直接打开 PGOS，walked=0、spotlight=0，不播放出发延迟与聚光。
- 浏览器控制台无 error/warn，9 项已有测试通过，15 项目、229 个原件哈希与 717 站内链接校验通过。
