# 手机地图交互修复验收

2026-10-31。基线为 `fd753f6`，原问题与截图位于相邻 `mobile-portrait-review-2026-10-31/` 目录。本轮保留像素风、Three.js 正交场景、原有路线与媒体数据。

## 已实现

1. 跨主题访问：拾取所有可见岛屿；放大状态下点击其他主题的项目会切换目标、从旅人当前位置求最短路并完成原有施法／详情流程。较近、足够大的其他主题岛屿会显示项目名，便于识别。KM 文章岛独立规则保留。
2. 统一手势：岛面、空白与 HTML 标牌共用 Pointer Events 状态机。拖动不会误触项目点击；双指依据距离与中心缩放，抬起一指可以继续拖动，取消不会留下幽灵点击。
3. 镜头响应：主题过渡期间不再禁用地图和标牌；手动拖动可接管当前实际镜头，直接跟手。普通主题／按钮缩放仍有缓动。
4. 手机布局：默认地图更近；简介改为紧凑图文行，技能标题横向滚动。模型裁切在介绍区下方，标牌避开介绍区。返回、前后浏览、缩放放在底部；主要控件和项目名命中区域至少高 44px。
5. 四号预览：保持遮罩与部分出画，手机上避开底部操作区；文章查看不会移动旅人。

## 浏览器实测

- 375×667、390×844、430×932：均无横向溢出，页眉不换行。主要头部／底部控件高度均为 44px；尺寸记录见 `sizes.json`。
- 375×667，Nex 介绍区约 115px；Rally 为 140px，相比原截图的 268px 大幅缩短，给地图留出更多空间。
- 从 Nex 标牌拖动 80×80px，标牌同步移动相同距离，释放后即停稳。普通动画中也已验证：过渡未完成时标牌仍可点，接手拖动后即刻停稳，见 `interrupt-transition.json`。
- AI 主题拖动后直接点击可见 PGOS，常规动画进入 `casting`，随后打开「PGOS 游戏联机后台」；没有先返回全景。见 `cross-theme.json`。
- 大幅向上拖动后，简介仍可读，模型由 Canvas 裁切，标牌不进入介绍区，见 `after-pan-375.jpg` 和 `clipping.json`。地图允许手动探索到别处，底部返回始终可恢复默认视角。
- 放大按钮、返回全景、KM 预览展开、三篇 Bot 文章与 44px 详情关闭键均已检查。
- 桌面 1440×900：全景、键盘主题选择与 Bot 访问正常。
- 无 WebGL 降级：缩放按钮隐藏，KM 主题与文章详情可操作。
- 控制台没有警告或错误。
