# 小岛悬停音效

保留 Rally 引擎／漂移／鸣笛与 Bot 语音，补齐其余 12 个项目。

- PhotoMuseum：卷展起点快门、旋转中的轻玻璃音、恢复屏风时的纸张声。
- NEX：随光标节奏播放短促键入声。
- PGOS：三个节点汇聚时轮流播放连接提示音。
- 云游戏：小球每次到达左右球拍时，播放不同音高和声像的击球音。
- 网游加速器：数据包绕过地球半圈、整圈时播放传输短音。
- 桌面玩机：同步图标起点与中途的双向传输提示。
- 垃圾清理：碎片收拢时播放轻收纳声。
- Win10 助手：磁贴依次展开的短音阶与收拢短音。
- 爱看段子 UWP：信息流滚动中的轻电子短音。
- 简致阅读：书页转到两侧极点时播放翻页摩擦声。
- iShowFX：照片流中的轻快门声。
- 西电导航：地图展开与收起时播放纸张声。

音效由 Web Audio 本地合成，没有新增媒体下载或循环底噪。使用动画的 elapsed time 调度，错过的动作不补播；音频缓冲复用。移开、换岛、静音、后台、打开详情或有声视频播放时，停止悬停音效，缓冲节点在播放结束后释放。

## 验证

- `npm test`：34 项通过，包含全部模型的音效事件、循环节奏、防止逐帧重复播放、波形余量和收声／不补播检查。
- `npm run build` 和 `npm run check` 通过，226 份原素材哈希一致。
- 浏览器真实悬停全部 12 个新增项目；AudioContext 为 playing，逐岛音效计数递增，静音时计数保持不变。记录见 `browser-checks.json`。
- 浏览器控制台无 warning/error。截图 `pong-hover.png` 展示云游戏悬停状态；音频调度结果以 JSON 记录为准，截图无法证明实际扬声器听感。
