# 页眉下的聚光灯连续性

2026-10-30。原先 header 占据独立的 86px／74px 高度，Three.js 画布及 traveler-focus 从其下方开始，行走暗场时形成一条浅色背景横带。

WebGL 模式改为透明悬浮页眉；场景与聚光灯遮罩共同覆盖完整视口。镜头取景加入实测页眉高度，简介维持原有垂直避让。页眉空白允许穿透，按钮保留操作；平面降级保留原本布局。

验证：
- 桌面 1910×1314：画布、场景和遮罩 top=0、height=1314，header 背景 rgba(0,0,0,0)。
- 手机 390×844：场景和遮罩 top=0、height=844，页眉高 74px，标题位于页眉下方。
- 实际访问 PhotoMuseum／Nex，行走聚光灯连续到顶；项目详情打开／关闭、字标简介打开／关闭、返回全景均正常。
- 构建、226 原件哈希与站内链接校验、25 项现有测试通过；浏览器控制台无警告或错误。
