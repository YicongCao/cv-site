# RPG 道具音效

2026-10-30。新增原创 0.88 秒上行琶音：C5、E5、G5、C6，柔和正弦／三角音色与短促玻璃质感泛音，不使用底噪。第一次用户操作时生成 PCM 缓冲，沿用现有 Web Audio 音效总线。

触发点是旅人到达、施法结束后进入 opening 阶段，即金色边框开始展开的同一帧。每个旅程 token 只触发一次；普通走路、抬手、直接深链接、即时打开及详情归位不触发。静音时消耗本轮事件，恢复声音不会补播；取消／改选、后台和有声视频会停止仍在播放的声音。

实际浏览器验证：从 PGOS 走到 Nex 后计数为 1；原地复访，opening 阶段计数为 2；静音复访，opening 阶段计数保持 2。检查见 checks.json，opening.png 为音效触发时的动画截图。结束后恢复原有声音开启设置及全景。

构建、29 项测试和资源校验通过，控制台无错误或警告。新增测试覆盖单次触发、取消、静音、后台、深链接和 PCM 的边界／响度／确定性。
