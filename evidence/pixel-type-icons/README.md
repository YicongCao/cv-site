# 像素字体、项目标牌与图标

2026-10-30。按最终收敛方向，小岛标题采用 18px（原 12px），以清楚、有节制为准；桌面图标 24px、手机 16px。正文 16px，项目用途说明 18–20px，行距约 1.7–1.85；所有作品站界面文字统一为自托管方舟像素字体，pixelcao 保留原有逐字跳动 SVG 字标。

14 个原创 16×16 SVG 轮廓：赛车／相框／代码终端／服务器组队节点／Pong／机器人／互联网地球／电脑手机／整理扫帚／Win10 窗格／信息流／书本／图文印刷／校园钟楼。图标置于项目标牌左侧，平面降级模式也保持一致。标牌碰撞时就近上下避让，原本不拥挤的位置保持不变。

验证：1440×900 全景、七项目客户端岛群、PhotoMuseum 长文详情；390×844 客户端标牌；14 个项目均有不同 SVG，平面模式也完整渲染 14 个图标。浏览器可见文字的计算字体均为 Ark Pixel 字体栈。构建与资源校验通过，26 项测试通过（含窄屏标牌重叠回归）。未修改简历原始 HTML 和截图内的文字。
