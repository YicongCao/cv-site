# 浮升石阶捷径验收

2026-10-31，采用 A「浮升石阶」。原有主题与项目位置不变。

## 行为

- 三条双向边加入同一张 Dijkstra 图：Bot ↔ 桌面玩机、Rally ↔ 云游戏、网游加速器 ↔ iShowFX。按实际场景距离选择，无强制触发。
- 接近已选中捷径入口时开始逐块升起：每块约 0.48 秒升起，块间错开 0.045 秒；走过后的块延迟约 0.16 秒，再用约 0.6 秒下沉淡出。
- 移动前检查整个扫过的落脚范围，前方石块未完全对齐则等待，等待时无步态和脚步音。
- Escape 在桥上取消后，角色位置保持不变，脚下石块保留；其余桥块消失。再次访问可以从该点安全返回。
- 跨主题桥梁两端保持可见、可访问；键盘 Enter 反向改选已验证最终打开桌面玩机。
- 减少动态效果直接定位并打开详情，三座临时桥均隐藏；平面降级全景保留 14 个可操作项目。

## 验证

- `npm test`：44 项通过，含全部 196 对起终点的门控移动、最短路径参考值和支撑断言；三组双向通行、连续改选、取消和即时定位。
- `npm run build`、`npm run check`：通过。228 个原件 SHA-256、809 项本地引用、简历链接有效。
- 实际浏览器逐一点击三组捷径，采样均仅对应桥梁显形，角色全程有已对齐的落脚点；未使用桥梁保持隐藏。Rally 与云游戏、加速器与 iShowFX 均核对到详情打开后桥梁完全收起。
- 390×844 手机取景：桥梁及两端小岛可见；文档无横向溢出。浏览器无新增错误或警告。
- 指针点击移动中的小标题，可能因镜头平移而点击到原位置的空白；空白仍按既有规则返回全景。桥上反向改选以键盘 Enter 做了稳定验证。

`routes.json` 保存六个方向的距离与 60 Hz 模拟步行耗时，不含首次聚光引导、施法与详情展开。路径距离分别减少 67.3%、56.3%、66.1%。

`browser-runs.json` 保存实际 DOM 状态采样；`bridge-journeys.mp4` 为同一批浏览器截图按采样间隔编码的无声回放。各组 `rise/crossing/retreat.png` 为关键帧，另有手机和桥上取消截图。
