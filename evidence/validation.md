# 本地验收记录 · 2026-10-30

交付入口：http://127.0.0.1:3000/ 。实现 A 白盒像素展厅，并纳入最后追加的交互要求：单图大图、多图瀑布流、视频自动静音播放。旧版的缩略图分页界面已移除。

## 内容和资源

- 15 个项目，230 份可展示去重素材；230 个原件 SHA-256 与原来源清单一致。
- 校验了 720 处本地引用，包含资源、封面、预览和简历链接。访客 JSON 无上级路径；内部来源清单不在 dist。
- Pillow 解码 471 份图片文件（含原件、封面、预览、简历重复依赖）；ffprobe 检查 14 个展示视频，均为 H.264。HEVC 转码最大边不超过 1920，已有兼容视频按原规格保留。详见 `media-audit.json`。
- 技术分享 PDF 原件可解析，共 60 页。pypdf 对原件交叉引用表给出修复读取警告；文件按原 SHA-256 保留，未重写或导出 PDF。
- 云游戏天梯 2019；西电导航无虚构年份。Nex 补充演示的具体关联仍沿用来源清单中的待核对说明。

## 独立性与服务

将 cv_proj 复制到 `/tmp/pixelcao-independent.tz7Oqy`，不复制 node_modules 和 dist，执行 npm ci、check、build、test，然后使用 3001 端口运行。过程不调用上级文件、FFmpeg 或 Python。

- 484 个唯一站内资源地址 HEAD 全部返回 200，见 `independence.json`。
- 在真实浏览器打开副本的 cloudgame 深链接，图片 URL 指向 3001，加载正常。
- 临时移走副本的一张图片和封面，验证图片失败提示及封面文字降级；随后还原原件并确认图片正常加载。
- 服务测试通过：GET、HEAD、MIME、单段 Range、尾部 Range、无效 Range 416、POST 405、404、编码非法路径、目录穿越、内部源码和清单不可访问。
- 实际再次尝试启动 3000 服务，明确报告端口占用并退出，没有自动换端口。
- 测试副本服务在验收后停止；交付服务 3000 保留运行。
