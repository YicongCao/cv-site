# 白帽旅人：入口、动效与个人叙事

2026-10-30。本轮保留深青黑纯色背景；没有加入海面、星空或其他背景方案。

## 已实现

- NEX、PGOS、Win10 改为一端固定的网格布旗，持续轻微飘动；文字自行绘制，Win10 使用主题蓝。网游加速器增加缓慢转动的经纬球体与金色联网轨道。
- 聚光束高度从 6 提升为 24 个世界单位，降低透明度，让光源从上方进入画面；保留跟随角色的暗场与脚下光圈。
- 普通首页入口为 4.5 秒演出：转头 → 抬手摸帽 → 镜头拉远。可跳过或按 Escape；项目深链接和减少动态效果直接进入内容。
- 点击岛面在命中位置出现 0.7 秒扩散光环；标签与查看按钮则在对应岛台中心反馈。拖拽不会产生点击涟漪。
- 摄像机切换主题时临时禁用移动中的场景标签与岛面点击，避免点击落到动画途中经过的其他岛。行走时仍可改选目的地。
- 页眉 pixelcao 改为个人简介入口：自绘像素旅人、Agent、游戏、显示器、方向、教育及联系方式图标；原生 dialog 支持焦点约束、Escape 和关闭后焦点恢复。
- PhotoMuseum / Brushline Rally 各以四个短章节展示产品、技术、设计、验证能力，并明确本人负责决策和验收、Codex 协作开发。手机先展示简介与视频，再显示能力章节。
- 背景帧在详情、个人简介打开或页面隐藏时暂停；减少动态效果时旗帜保持静止，不播开场。
