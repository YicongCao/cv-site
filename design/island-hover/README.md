# 小岛悬停循环

2026-10-30。展台与桥梁保持原布局，独立运动部件保留为动态几何体，其余方块继续实例化。鼠标悬停岛面、项目名或键盘聚焦项目名可预览；离开后复位。点击仍访问项目，开详情时停止悬停循环与声音。

## 项目动作

- Brushline Rally：沿椭圆赛道行驶 → 漂移扬尘 → 停下 → 鸣笛 → 平滑驶回起点。8 秒一轮；引擎随速度变化，漂移带摩擦声，鸣笛每次停车只响一次。
- Bot：机器人轻轻摇摆；方舟像素字体气泡逐字显示“你好”“什么是喷气背包？”“去哪获取铁矿石”。每字 140ms，打满停留 300ms，消失 160ms 后下一句。有本地中文语音时，以较高音调和较快语速朗读文案；仅选用 localService 的中文语音。没有可用本地语音时使用原创电子拟声，不请求远程语音服务。
- PhotoMuseum：三张像素风景展片由平面弯折到圆柱侧面，转两圈，展开回到原展墙；10 秒循环。
- 云游戏：小球在左右拍之间持续往返，拍子垂直跟随接球位置；球到边缘时与对应拍子相遇。
- 网游加速器：亮色数据包沿地球轨道运动。
- 西电导航：增加永久钟楼，悬停展开三折校园地图，再折回。
- iShowFX：照片瀑布流持续斜向滚动，由画布边界裁切。
- Nex：终端游标逐行扫描代码；PGOS：组队节点汇入服务器；桌面玩机：数据在桌面与手机之间同步；垃圾清理：碎片归拢进整理台；Win10：磁贴菜单展开收回；UWP：信息卡片流动；简致阅读：书页翻动；Kinect：车轮辐条和踏板旋转，传感器轻微响应。

背景流星每 10–15 秒随机出现一小组（两颗），只在闲置浏览时运行。原始截图与视频内容不变。手机气泡限制在视口内。详情、页面隐藏、减少动态效果和 WebGL 降级场景不会播放这些装饰循环。音效服从原声音开关，需要浏览器允许的首次用户交互后启动。

### 流星方向与造型调整

流星改为从右上向左下横越，彗尾始终指向右上并与视口对角轨迹保持一致；星核使用 16px 阶梯轮廓的四角星，中心有亮色像素。每颗持续 2.8–3.3 秒，透明度从出现起单调降低至零；保留 10–15 秒一组、每组两颗的间隔与降级规则。测试补充验证 x 减少、y 增加以及透明度递减，25 项测试通过；浏览器实测并保存 `design/meteor-diagonal/meteor.png`，控制台无 error / warn。
