# A 方案依据

`01-white-gallery.png` 来自用户在本会话选择的 A 概念图；原图：`portfolio/planning/pixel-directions/01-white-gallery.png`。设计采用象牙白、炭黑、朱红，像素字标、阶梯投影、独立像素底座和薄板展架。截图保持原比例与可读性。概念图中示意年份不作为事实依据。

`source-ledger.json` 保存 Gallery 素材来源、原始 SHA-256、排除和重复记录、视频转换元数据，只用于本地审计，不复制到 dist。用户确认：云游戏天梯 2019；GSTM 是 PGOS 客户项目；西电导航是毕业设计、不推断年份；JS 黑洞排除。Nex 的 1024 × JEV 补充演示沿用原档案归属，其具体关联仍以原清单待核对说明为准。

`pixel.js` 的字母/数字为自绘 5×7 点阵，不使用外部字体。Three.js MIT 许可见 `three-license.txt`。
