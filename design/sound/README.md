# Quiet Islands — 展馆声音

2026-10-30。轻柔、空灵、有空间感的原创声音设计，使用留白、长音和少量钟音营造微缩世界氛围。

- BGM：`public/audio/quiet-islands.mp3`，64 秒循环、32 kHz 立体声、128 kbps，约 1 MB。四组缓慢交叠的和声、原创稀疏旋律和立体声扩散回声；没有使用第三方配乐或采样。
- 点按：Web Audio 正弦钟音，两层音高，短衰减；90 ms 内重复事件合并，避免同一次点击的两条事件链叠音。
- 脚步：低频轻敲与低通噪声，左右轻微交替。与角色动画共用移动距离（每 π / 1.25 世界单位一步），站立、起步等待、取消与定位不播放脚步，不用定时器伪造步行。
- 音量：BGM 首次淡入，详情中约降至正常音量的三分之一；视频播放且取消静音后 BGM 淡出，恢复静音或暂停后恢复。音效与 BGM 共享总开关，视频自身控件保持独立。
- 入口：首次用户交互才初始化音频上下文。页眉、项目详情、放大浏览和个人简介均有开关；记住静音选择。页面隐藏时暂停上下文，回前台恢复；不支持音频时不妨碍作品浏览。

生成脚本：`node scripts/compose-audio.mjs`（仅重新创作时需要本机 FFmpeg）；日常 build / start 直接使用已经生成的 MP3，不需要额外音频服务或工具。旋律与渲染参数保存在脚本中，采样峰值、RMS 等记录在 `render.json`。

## 鞋底摩擦声修正

用户反馈上一版听不到沙沙脚步。检查发现原有摩擦层只有 90 ms、增益 0.035，且额外低通至 950 Hz，实际偏向轻敲。现在用 190 ms 的双段摩擦包络，预处理去掉低频轰鸣和尖锐高频；摩擦层增益改为 0.50，左右脚使用不同噪声样本并轻微左右分布，取消原来的低频正弦敲击。

- `makeFootstepSamples` 是运行时与预览共用的波形来源；`node scripts/preview-footsteps.mjs` 输出 `footsteps-preview.wav`，按实际总线增益渲染 8 步。
- 新增波形能量、首尾包络和峰值余量验证，17 项测试通过；构建与 229 素材校验通过。
- 浏览器实测行走 34.86 单位触发 13 步；下一次行走按 Escape 后在第 14 步停止，随后检查仍为 14。音频处于 playing，控制台无警告 / 错误。
